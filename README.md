# DIY 측정 지그 3D

측정 지그 3D 보기. 앞줄은 제작판(10/22 주문 기준, 몸체 POM: 싱글 v2·탠덤 v4), 뒤 두 줄은 이전 판(탠덤 v2–v4, 싱글 v1·v2, PL 캐리어). 부산대 이동현, 2026-10-22 (10-24 설계 검토 반영, 싱글 B = 한 줄 4화소 S-B 기판 모델 추가) (10-23 제작 탠덤: 십자 창 윗판, 핀 ±6.45, 뒷창 Ø15).

- 끌어서 회전, 분해 슬라이더(고른 지그만 펼침), 부품 분류 색, 부품을 누르면 판매 링크.
- 형상은 설계용 개념 모델(STEP과 같은 치수)이며 제작도는 아니다.
